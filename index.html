Content Studio

Content Studio is a private desktop tool that runs only on the owner's own computer. It cuts the owner's own gameplay recordings into short vertical clips and, after the owner has reviewed and approved each clip, uploads it to the owner's own YouTube channel (YouTube Data API), Instagram account (Instagram API with Instagram Login) and TikTok account (TikTok Content Posting API, as drafts).

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy and our Privacy Policy.

It is not offered to the public and is only used with the owner's own accounts.
