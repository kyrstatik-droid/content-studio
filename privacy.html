Privacy Policy

Last updated: 18 November 2026 (Instagram and TikTok added)

Content Studio is a desktop application that runs locally on the owner's computer and is used only with the owner's own YouTube, Instagram and TikTok accounts.

Data accessed

With the user's permission, the app uses the YouTube Data API to read the user's own channel information, video list and public statistics (views, likes, comments) and to upload videos the user has approved.

Instagram (Meta): with the permissions instagram_business_basic and instagram_business_content_publish, the app reads the user's own Instagram username and account ID and publishes Reels the user has approved to that account.

TikTok: with the scopes user.info.basic and video.upload, the app reads the user's own TikTok display name and uploads approved videos as drafts to the user's TikTok inbox, where the user reviews and posts them in the TikTok app.

Storage

All data, including access tokens, is stored only on the user's own computer. No data is sent to any server operated by the developer, sold or shared with third parties. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Data retention and deletion

Video lists, titles and statistics are fetched live from the YouTube API when displayed and are not stored permanently. Downloaded source recordings and rejected clips are deleted automatically after 7 days. Any YouTube API data stored locally is refreshed or deleted within 30 days. The user can delete all data at any time by deleting the app folder or by contacting us at the address below.

Data deletion instructions (Instagram / TikTok): click "Trennen" (disconnect) for the account in the app, which deletes the stored access token. To remove the app's access on the platform side, open Instagram → Settings → Website permissions → Apps and websites → remove "Content Studio", or TikTok → Settings and privacy → Security → Apps and services → remove "Content Studio". To have any remaining data deleted, email the address below; we will confirm deletion within 30 days.

Revoking access

Access can be revoked at any time in the app ("Trennen"), via the Google security settings page at security.google.com/settings/security/permissions, or in the Instagram and TikTok app settings as described above. Deleting the app folder removes all locally stored data.
