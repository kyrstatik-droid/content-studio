Privacy Policy

Last updated: 18 November 2026

Content Studio is a desktop application that runs locally on the owner's computer and is used only with the owner's own Google/YouTube account.

Data accessed

With the user's permission, the app uses the YouTube Data API to read the user's own channel information, video list and public statistics (views, likes, comments) and to upload videos the user has approved.

Storage

All data, including access tokens, is stored only on the user's own computer. No data is sent to any server operated by the developer, sold or shared with third parties. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time in the app ("Trennen") or at myaccount.google.com/permissions. Deleting the app folder removes all locally stored data.
